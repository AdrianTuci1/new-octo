description: Use this skill when the user wants to start a brand-new project, scaffold a repo, or choose an initial stack and structure.
---

# create-new-project

- Gather only the essentials: project goal, tech stack, target path, and any must-have tooling.
- If the stack is not fixed, offer 2-3 strong defaults.
- Prefer a minimal, working scaffold over a large template.
- State the directory layout and first run command.
- Call out any irreversible setup choices before making them.
