---
name: fork
description: Use this skill when the user wants to branch the current work into a new direction, try an alternative approach, or continue in a separate path without losing the current one.
---

# fork

- Clarify what should stay the same and what should change in the new branch.
- Summarize the parent context in a few bullets before branching.
- Name the new branch of work clearly.
- If multiple options exist, list them briefly and pick the most likely one unless the user asks to choose.
- End with the first concrete action for the forked path.
