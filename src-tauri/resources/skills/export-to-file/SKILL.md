# export-to-file

- Determine the target file path and format first.
- If the path is missing, ask for it once or make a reasonable default and state it.
- Shape the content for the file format instead of copying raw chat text.
- Prefer clean headings, bullets, or machine-readable structure as appropriate.
- Confirm what was written and where.
