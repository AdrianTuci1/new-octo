# compact

- Produce a short bullet summary.
- Keep only: current goal, important decisions, blockers, files or paths that matter, and next actions.
- Prefer 5-8 bullets total.
- Drop chatter, repeated history, and low-signal detail.
- If the user asks to continue later, end with a minimal restart prompt they can reuse.
