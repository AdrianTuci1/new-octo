# add-prompt

- Capture the prompt intent, expected inputs, and desired output style.
- Rewrite the prompt to be reusable, concise, and parameterized where helpful.
- If there is a prompt library or storage target, add or update the entry there.
- If storage is not available yet, return a final reusable prompt block the user can keep.
