# create-environment

- Start with short bullets.
- Distinguish between:
  - local environment
  - cloud environment in a separate tab
  - cloud execution from the current chat
- If the user wants a separate cloud tab, recommend this path over `/cloud-agent`.
- Explain the minimum setup needed for each option.
- Ask only for the missing detail that decides where the environment should live.
