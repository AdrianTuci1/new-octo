# fork-and-compact

- Do two outputs in order:
  1. a compact handoff for the current thread
  2. a short kickoff for the forked path
- Keep both outputs in bullets.
- Preserve decisions, risks, and next actions.
- Make the handoff shorter than the fork kickoff unless the user asks otherwise.
