# fork-from

- First identify the exact point to branch from.
- Restate only the context that was true at that point.
- Ignore later assumptions unless the user says to keep them.
- Present the fork as a fresh path with a short goal and first action.
- If the branch point is ambiguous, ask one precise disambiguation question.
